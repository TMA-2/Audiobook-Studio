# 0.9.1-0.9.2 Selection Metrics & Workflow Fixes Plan

## Overview
This plan addresses several key usability, bug fix, rate-limiting, and metric improvements requested by the user:
1. Fix `activeGenerationId` validation to verify that a matching generation object exists in `snippet.generations` before enabling playback or displaying active status.
2. Add a Chapter Delete button with a confirmation modal in the main chapter header.
3. Ensure snippet splitting inherits the parent snippet's `sceneId`.
4. Fix generation deletion to clear `generationId` across *all* snippets referencing it.
5. Fix generation model name logging to avoid `(unknown)` fallback by properly referencing `project.settings.model.name || project.settings.model.id`.
6. Log `temperature` value on generation objects and display it in the Generation History sidebar.
7. Simplify the Snippet Selection Header (Bulk Operations Ribbon): remove speaker/scene dropdowns and display selection & prompt cumulative metrics (full prompt chars/words, selected snippet chars/words, prompt overhead).
8. Fix One Dark CSS class definitions in `src/index.css` by adding leading `.` class selectors.
9. Simplify prompt template scene interpolation: remove `{scene_description}` placeholder and use `{scene_context}` exclusively (mapping `scene.context || scene.description || "No context."`).
10. Implement rate-limited parallel generation for `individual` mode bulk actions (Generate Selected, Generate Chapter, Generate All): pool requests with max 9 concurrency and rate-limit to <= 10 requests per minute.

## Detailed Steps

### Step 1: `src/index.css` One Dark Class Selectors
- Add leading `.` to `.fg-onedark-*` and `.bg-onedark-*` class definitions so custom typography styles render correctly.

### Step 2: Fix Snippet Splitting Scene Inheritance in `src/services/appStateModifiers.ts`
- In `splitSnippet`, pass `sceneId: snippet.sceneId` to the newly created snippet object.

### Step 3: `activeGenerationId` Check & Multi-Snippet Generation Deletion in `src/App.tsx`
- Ensure `hasAudio` and audio play button enable states check `snippet.activeGenerationId && snippet.generations.some(g => g.id === snippet.activeGenerationId)`.
- Update `handleDeleteGeneration` to clear `generationId` from `generations` array and reset `activeGenerationId` across **all** snippets in all chapters.

### Step 4: Generation Model Name & Temperature Tracking
- Update `Generation` interface in `src/types.ts` to include optional `temperature?: number`.
- In `handleGenerateSnippet` and `handleBulkGenerate`, ensure `model` is set to `project.settings.model.name || project.settings.model.id || 'Gemini Flash'` and `temperature` is recorded.
- Update Generation History UI in `src/App.tsx` to display model and temperature when available.

### Step 5: Chapter Deletion in Chapter Header
- Add a trash icon button to the Chapter Header action controls (next to Wand2, Play, Download) that triggers the confirmation modal before deleting the chapter.

### Step 6: Snippet Selection Header Metrics & Refactor
- Remove speaker and scene assignment dropdowns from the bulk operations ribbon.
- Calculate selection character and word count, full prompt character and word count (via `compilePrompt`), and prompt overhead (`fullPromptCharCount - selectedSnippetCharCount`).
- Render these cumulative metrics clearly inside the selection ribbon.

### Step 7: Prompt Template Scene Interpolation Simplification
- In `src/utils/promptCompiler.ts`, `src/components/SettingsDialogue.tsx`, and `DEFAULT_PROMPT_TEMPLATE`:
  - Remove `{scene_description}`.
  - Use `{scene_context}` interpolated with `activeScene.context || activeScene.description || "No context."`.

### Step 8: Rate-Limited Parallel Batch Generation for Individual Mode
- Implement a throttled batch execution helper (`runThrottledBatch`) in `src/App.tsx` / `src/services/audioService.ts`.
- When `project.settings.generationOption === 'individual'` during bulk operations (Generate Selected, Generate Chapter, Generate All):
  - Execute requests concurrently up to a max pool size of 9 active requests.
  - Enforce a rate-limiting sliding window / delay ensuring total launched requests remain <= 10 per 60-second window.

### Step 9: Tests, Lint & Build Verification
- Update or create test cases in `tests/` verifying prompt compilation, state modifier logic, and rate-limiting behavior.
- Run `npm run lint` and `compile_applet`.
- Update `package.json` to `0.9.2` and update `CHANGELOG.md`.
