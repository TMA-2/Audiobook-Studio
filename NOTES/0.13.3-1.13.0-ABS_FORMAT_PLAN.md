# ABS Project Format v4 Plan

Start version: 0.13.3. Finished: 1.13.0-testing (2026-11-05).
Status: complete. Steps 1-9 done; verified by hand on Teacher's Pet (320 MB sidecar -> 58 MB .abs).

## Goal

Replace `project.json` + base64 `project.audio.json` sidecar with a single `.abs` zip. Audio stays binary end to end (IndexedDB Blob -> zip entry).

Largest current project: `maxine_and_alice`, 1.1 MB JSON + 1.3 GB sidecar. Base64 adds about 33%, so the same audio is about 0.98 GB as binary.

## Layout

- `project.json`, validated by `schema/abs-project.schema.json` (user maintains the schema)
- `generations/<generationId>.<ext>`: raw audio in its generated format; extension from `audioMimeType`
- Zip method STORE for all entries

## Versioning

`<major>.<minor>.<patch>-<label>`, label `testing` until stable, no build metadata. v3 JSON + sidecar stay readable and convert on save.

## Decisions

1. Speaker `role` is exported and imported (currently lost on reload). `pace` and `accent` are removed everywhere: `Speaker` interface, `{speaker_pace}` / `{speaker_accent}` in `promptCompiler.ts`, the default prompt template, `markdownParser.ts`, and the Settings UI if present.
2. Dead `Speaker` fields removed: `pacing`, `pitch`, `emotion`, `customInstructions`, `model`. The matching `req.body` reads in `server.ts` are removed.
3. Settings are exported through an allowlist: `model`, `temperature`, `encoding`, `sampleRate`, `promptTemplate`, `generationOption`, `apiType`, `concatenationOption`, `sheetsLoggingEnabled`, `sheetsLoggingSpreadsheetId`, `sheetsLoggingSpreadsheetUrl`. `apiKey` is never exported: a key encrypted with a key stored in the same file gives no protection, and projects sit in OneDrive. `bitRate` and `audioExportFormat` are not exported until export uses them.
4. Sheets logging is saved in the project. On import, logging defaults to on when a sheet ID or URL is present.
5. `settings.model` accepts a string or a `ModelOption` object; `sampleRate` accepts string or number (`resolveModelId` already covers the model).

## Open question

Sheet ID is read from `userPreferences.sheetsSpreadsheetId` (global) in `App.tsx`, while `Project.settings` also has `sheetsLoggingSpreadsheetId`. Decision needed on which one wins when both exist; proposed: the project value, falling back to the preference.

## Steps (each: failing test first, then code)

1. Remove `pace` / `accent` and the dead `Speaker` fields; update affected tests.
2. Speaker `role` export/import round trip.
3. Settings allowlist export; `apiKey` and unlisted keys excluded.
4. Sheets settings round trip and the "default on when sheet present" import rule.
5. `version` field (integer, per the schema) and v3 -> v4 reader at the file boundary: no `version` means v3, newer than 4 is rejected, `model` string or object and `sampleRate` string or number are accepted.
6. Store audio in IndexedDB as Blob instead of base64.
7. `.abs` writer/reader (fflate, streaming), STORE method.
8. Open v3 + sidecar projects, save as `.abs`; stop writing sidecars. (Done 2026-11-05: Save writes `.abs`; Open takes `.abs` or v3 `.json`; the v3 `.audio.json` loader stays; the sidecar save button is removed. `sidecarExporter.ts` is no longer called and can be deleted at release.)
9. CHANGELOG, package.json -> 1.13.0-testing, rename this plan to `0.13.3-1.13.0-ABS_FORMAT_PLAN.md`.
