# Generation Container & Unified Selection Header Plan

## Overview
This plan restructures the snippet list and chapter header to reflect multi-snippet audio generations visually, provide unified sticky chapter/selection controls, and streamline playback and generation statistics.

---

## Key Changes

### 1. Data Model & Generation Identification
- Add optional `name?: string` and generation metadata helpers to `AudioGeneration` / `Snippet` in `src/types.ts`.
- Add helper to compute default generation label:
  `⌚<hh:mm:ss>-↔️<duration>-🔖<chapter_index>-🎬<scene_name>-💬<snip_start>-<snip_end>` (e.g., `07:53:20-D1:12-Ch7-Ln7-9-Title`).
- Provide continuous playback logic that iterates through contiguous generation blocks rather than replaying individual snippets for multi-snippet generations.

### 2. Generation Group Container UI ("Material-like" Yellow Enclosure)
- In `ChapterView` / `SnippetList`, detect contiguous spans of snippets that share an `activeGenerationId`.
- Wrap the grouped snippets in a yellow-themed container (`border-yellow-500/60`, subtle amber tint background).
- **Upper-Left Generation Header & Flank**:
  - **Top Bar**:
    - Editable generation label/name.
    - Generation stats: Speaker count (1 or 2), Total Chars & Words, Request Tokens / Stats.
    - Action buttons: Play, Play From Here, Stop, Regenerate, Export.
  - **Left Flank Controls**:
    - Vertical iconified quick-controls (Play, Play From Here, Stop).
  - Remove redundant per-snippet generation playback buttons from snippets within an active generation block.
  - Fallback / Discrete generation handling: If a single snippet in a range is set to an individual discrete generation, display inline playback scoped to that snippet.

### 3. Snippet Row Polish
- Add `N/T` snippet indicator pill (e.g., `3/24`) immediately after the checkbox and before the speaker dropdown.
- Make Speaker and Scene selector widths auto-size according to text length (`w-auto` / `max-w-max`).
- Move iconified `Add Below` button between `Combine with Next` and `Delete`.

### 4. Combined Chapter & Snippet Selection Header
- Make chapter header sticky under the top bar during scrolling.
- **Dynamic Stats Display**:
  - 0 snippets selected: Display chapter totals (words, chars, token count estimate).
  - 1+ snippets selected: Display cumulative selection stats (words, chars, selected snippet count).
- **Expandable Sub-Row**:
  - Contains selection action buttons: "Generate", "Delete" (clean labels without redundant "selected" suffix) and chapter actions that wrap cleanly on narrower screens without clipping default speaker controls.
  - Add "Scroll to top" button (`↑ Top`).

### 5. Token Count Endpoint / Service (`countTokens`)
- Implement server-side route `/api/count-tokens` utilizing `@google/genai` `client.models.countTokens` (or prompt token estimation fallback).
  - Reference [`countTokens()`](https://ai.google.dev/gemini-api/docs/generate-content/tokens#count-tokens) documentation.
- Add frontend client method `getTokenCount(prompt, model)` in `src/services/apiService.ts`.
