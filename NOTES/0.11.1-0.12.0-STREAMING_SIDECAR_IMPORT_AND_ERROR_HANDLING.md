# Streaming Sidecar Import and Error Handling Implementation Plan (Completed in v0.12.0 - 2026-08-30)

## Problem
When loading large sidecar JSON files (e.g. 650MB), `FileReader.readAsText()` and `JSON.parse()` fail with `SyntaxError: Unexpected end of JSON input`. In Chromium/V8, reading a 650MB file into a contiguous JavaScript string exceeds maximum string length limits (~512MB) or causes buffer truncation and memory exhaustion.

## Proposed Solution
Implement a streaming sidecar JSON importer (`src/utils/sidecarImporter.ts`) that reads the file in manageable chunks using Web Streams / `File.stream()` with `TextDecoder({ stream: true })`.

As each generation item in the `generations` array is parsed:
1. Parse only the individual item JSON string.
2. Save the audio payload directly into IndexedDB (`saveAudio`).
3. Store only lightweight metadata (without the base64 audio string) in memory to update chapter snippets.
4. Report import progress (bytes processed, total bytes, percent, and count of imported items) in the UI.
5. Provide detailed error messages with byte position and context if parsing or database storage fails.
