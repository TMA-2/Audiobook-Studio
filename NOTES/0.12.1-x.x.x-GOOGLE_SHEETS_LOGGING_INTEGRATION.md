# Google Sheets Logging Integration Plan

## Problem & Goal
Track generation metrics, API costs, model choices, text length, duration, and error logs directly to a Google Spreadsheet.
This enables long-term observability across sessions, cost analysis for Gemini TTS, and historical record keeping without requiring a complex backend database.

### Fields to Log
- Timestamp (unix epoch?)
- Status
- Status Message / Details (e.g. for error information)
- API Response Time (ms)
- Project Name
- Chapter Name
- Speaker 1 (default for single-speaker)
- Voice 1
- Speaker 2 (generations can't have more than two speakers, so...)
- Voice 2
- Model
- Temperature
- Starting Snippet index
- Ending snippet index
- Raw Character Count (joined snippet text length)
- Raw Word Count
- Request Character Count (assembled prompt text)
- Request Word Count
- Request Tokens
- Response Tokens
- Audio Duration (ms)
- Audio Size (b)
- Note (for future use)

**Example**
```csv
timestamp, status, status message, response time, project, chapter, speaker 1, voice 1, speaker 2, voice 2, model, temp, snippet start, snippet end, text chars, text words, prompt chars, prompt words, req tokens, resp. tokens, audio duration, audio size, note
```

## Architecture & Integration Strategy
1. **Client-Side OAuth Flow**:
   - Trigger OAuth flow with scope: `https://www.googleapis.com/auth/spreadsheets`.
   - In-memory token storage (Google Identity Services / Firebase Auth token pattern).
   - Clean connection states in UI (Connected as user, Disconnected, Re-authenticate).

2. **Sheets Service (`src/services/sheetsService.ts`)**:
   - `createLoggingSpreadsheet(accessToken, projectName)`: Creates a new formatted spreadsheet with [pre-defined headers](#fields-to-log) detailed above
   - Spreadsheet file name should be `AudiobookStudioLog-yyyy` with new sheets/tabs added by month
   - `appendGenerationLog(accessToken, spreadsheetId, logEntry)`: Appends generation rows using Google Sheets API `spreadsheets.values.append` with `USER_ENTERED`.
   - `validateSpreadsheet(accessToken, spreadsheetId)`: Confirms access to the target sheet and verifies/creates header rows.

3. **Logging Triggers in Audio Pipeline**:
   - Hook into single-snippet synthesis and contiguous multi-snippet block synthesis in `src/App.tsx` / `geminiService.ts`.
   - Asynchronous and non-blocking: logs in the background so audio playback and UI responsiveness are never hindered by network latency to Sheets API.
   - Captures both successful generations and failed attempts (with error message & model details).

4. **UI & Settings Management**:
   - Settings dialog section for **Google Sheets Logging**:
     - Google Account connection button & status badge.
     - Spreadsheet ID / URL field with quick link: "Open in Google Sheets".
     - "Create New Log Spreadsheet" action button.
     - "Test Logging Row" button.
     - Toggle: "Auto-log generations to Google Sheets" (persisted in project/user preferences).
